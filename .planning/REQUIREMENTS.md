# Requirements

## Must Have

- Owner-only passwordless authentication with private database and media access.
- Search-first responsive UI, editable SCORE taxonomy, personal tags, saved topics, and recent topics.
- Flexible AI-composed topic blocks with claim-level source provenance and explicit approval.
- Immutable approved versions with later draft revisions and restore.
- Offline approved-topic search and reading for saved or recent content.
- Reviewed cloze export to AnkiMobile, AnkiConnect, and UTF-8 import fallback.
- One-click portable backup and a complete choledocholithiasis seed topic.
- PWA manifest, home-screen installability, noindex, PHI blocking, and server-only secrets.

## Not in V1

- Public sharing, multiple users, patient-linked notes, PDF ingestion, source scraping, chat, quizzes, or an internal spaced-repetition scheduler.
